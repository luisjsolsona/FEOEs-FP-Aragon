# Prospección de empresas — Familia Informática y Comunicaciones (Zaragoza)

Listado de 96 empresas TIC de Zaragoza como punto de partida para la prospección
que el Decreto 91/2024 (art. 57.4) asigna al tutor/a dual general.

- `Prospeccion_empresas_IFC_Zaragoza.xlsx`: listado con columnas de seguimiento
  (estado de convenio, tutor responsable, contacto, resultado) y hoja Resumen.
- `prospeccion_empresas_IFC_zaragoza.csv`: mismo listado en CSV, importable en la app.

Categorías: soporte IT a empresas, redes/telecos/ciberseguridad, consultoras y
grandes empresas TIC, organismos públicos, desarrollo software/web, distribución y tiendas.
Perfil orientativo por ciclo (SMR / ASIR / DAM / DAW) y prioridad (Alta/Media/Baja).

Fuente: Google Maps (sept. 2026) + empresas TIC conocidas de Zaragoza.
Verificar teléfonos y direcciones antes de formalizar convenios.
